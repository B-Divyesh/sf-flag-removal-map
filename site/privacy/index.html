FIELD POLICY / 2026-08-27

Privacy is the default terrain.

Flag Removal Map does not collect, transmit, sell, or store your flag exports, evaluation data, repository contents, or demo inputs.

CLI

The CLI runs locally, performs no network requests, and includes no telemetry. It reads only the paths you provide and writes only the requested report.

Website

The browser demo runs entirely on your device. Inputs are not persisted. The site has no analytics, advertising, third-party scripts, accounts, cookies, or remote fonts.

Hosting logs

The hosting platform may retain short-lived operational request logs such as IP address, user agent, path, and timestamp for security and reliability. The project does not use those logs for profiling.

Questions

Open an issue in the public source repository for privacy questions or security reports that do not contain secrets.
