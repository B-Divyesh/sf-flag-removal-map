WHY MORE EVIDENCE IS NEEDED

A flag’s age is not removal evidence.

A provider export and repository search answer different questions. Compare both before changing a completed flag.

A zero evaluation count can support review. It never proves a flag is safe to remove.

Built-in decision rule
INSTALL THE CLI

Build a local removal plan.

Build and install the CLI from source.

cargo install --path .
flag-removal-map --flags ./flags.json --evaluations ./evaluations.json --repo ./apps --out ./removal-plan.md

Run the bundled CLI demo

Classification meanings

Keep
Enabled status or evaluations in the dated usage report.
Removal candidate
Completed status and recent, dated zero evaluations. Review is still required.
Review
Missing, stale, conflicting, or incomplete evidence.
PRODUCT BOUNDARIES

What the CLI will not do.

  • It does not edit code.You decide what each reference means.
  • It does not call providers.The CLI reads the export files you provide.
  • It does not certify safety.The plan lists evidence and human checks.
